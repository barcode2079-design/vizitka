# Голенко Андрей — Персональная визитка

Интерактивная персональная визитка в стиле фильма **Трон**. Включает анимированный неоновый фон с городом, сеткой перспективы и проезжающими светоциклами.

## Возможности

- 🎯 Полностью интерактивная визитка
- 🌆 Анимированный фон в стиле Трона с неоновым городом
- 🏍️ Светоциклы, проезжающие вдалеке каждые 45 секунд
- 📱 Адаптивный дизайн для мобильных и десктопных экранов
- ⚡ Без внешних зависимостей — чистый HTML, CSS и JavaScript
- ♿ Доступный интерфейс с поддержкой системных предпочтений анимации
- 🎨 SVG иконки для социальных сетей

## Быстрый старт

Просто откройте файл в браузере:

```bash
open vizitka.html
```
